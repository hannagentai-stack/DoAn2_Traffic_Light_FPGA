1. CAU TRUC DU AN SAU KHI DONG GOI:
--------------------------------------------------------------------------------
- traffic_light_top.qpf   : File du an Quartus Prime (Mo bang Quartus Prime)
- traffic_light_top.qsf   : File cau hinh chan, chuan logic va dong chip EP4CE6E22C8N
- traffic_light_top.sdc   : File rang buoc thoi gian TimeQuest (Timing Constraints)
- traffic_light_top.sof   : File nap bitstream truc tiep vao FPGA qua USB-Blaster
- clk_divider.vhd         : Module chia tan so 50 MHz sang xung 1Hz va xung chop vang
- fsm_controller.vhd      : Module may trang thai FSM Moore 6 trang thai
- timer_counter.vhd       : Module bo dem lui thoi gian va giai ma BCD bang phep so sanh tru
- seg7_decoder.vhd        : Module giai ma LED 7 doan (Cathode chung Active-High)
- Danh_Sach_Linh_Kien_Do_An_Traffic_Light.docx : Bang thong ke linh kien & du toan mua sam BOM (Cathode chung)
- Danh_Sach_Chan_IO_FPGA_Cyclone_IV.docx       : Bang tra cuu chi tiet 29 chan cam I/O kem so do 10 chan LED 7 doan
- traffic_light_top.vhd   : Module Top-level tich hop toan he thong va mach khoa Fail-Safe
- tb_traffic_light_top.vhd: Testbench kiem chung toan dien 7 kich ban hoat dong
- Chay_Mo_Phong_ModelSim.bat : File kich hoat tu dong mo ModelSim va nap song
- sim/                    : Thu muc chua cac file kich ban mo phong ModelSim (run_sim.do, wave.do)
- Bao_Cao_Giai_Thich_Code_Va_Nguyen_Ly_Module.docx : File bao cao Word giai thich code chi tiet

--------------------------------------------------------------------------------
2. HUONG DAN BIEN DICH VA NAP XUONG CHIP TREN QUARTUS PRIME:
--------------------------------------------------------------------------------
Buoc 1: Mo phan mem Quartus Prime (phien ban 13.0, 18.1, 20.1 hoac moi hon).
Buoc 2: Chon File -> Open Project -> Chon file "traffic_light_top.qpf".
Buoc 3: Nhan to hop phim "Ctrl + L" (Start Compilation) hoac bam nut Play mau xanh
        de bien dich toan bo du an. (Thoi gian khoang 20 - 30 giay).
Buoc 4: Mo Quartus Programmer (Tools -> Programmer).
Buoc 5: Cam mach FPGA qua cap USB-Blaster, nhan "Hardware Setup..." va chon "USB-Blaster".
Buoc 6: Nhan "Auto Detect" hoac chon file "traffic_light_top.sof", tich vao o "Program/Configure".
Buoc 7: Nhan "Start" de nap chuong trinh vao chip FPGA.

--------------------------------------------------------------------------------
3. HUONG DAN CHAY MO PHONG DANG SONG TREN MODELSIM:
--------------------------------------------------------------------------------
Cach 1 (Nhanh nhat - 1 Click):
- Nhan dup chuot vao file "Chay_Mo_Phong_ModelSim.bat".
- Phan mem ModelSim se tu dong bat len, tu dong bien dich cac file VHDL va ve san
  toan bo dang song 250 us len man hinh Wave.

Cach 2 (Chay bang tay trong ModelSim GUI):
- Mo phan mem ModelSim (hoac QuestaSim).
- Vao menu: File -> Change Directory... -> Tro toi thu muc "sim" cua du an.
- Tai thanh lenh Transcript o duoi man hinh, go dong lenh:
      do run_sim.do
- Nhan Enter, ModelSim se tu dong thuc thi va hien thi dang song.
- Nhan phim "F" tren ban phim de phong to toan man hinh (Zoom Full).

--------------------------------------------------------------------------------
4. SO DO GAN CHAN I/O TOI UU CHO VE PCB (ZERO-CROSSING ROUTING):
--------------------------------------------------------------------------------
* Xung nhip thach anh: CLOCK_50 -> PIN_24 (50 MHz on-board oscillator)

* TOP HEADER (Cum Den giao thong & Dieu khien - PIN_38 den PIN_53):
  - LEDG[0] (Xanh A) : PIN_38        |  LEDG[1] (Xanh B) : PIN_43
  - LEDR[0] (Vang A) : PIN_39        |  LEDR[2] (Vang B) : PIN_44
  - LEDR[1] (Do A)   : PIN_42        |  LEDR[3] (Do B)   : PIN_46
  - KEY[0] (Reset)   : PIN_49
  - KEY[1] (Khan A)  : PIN_50
  - KEY[2] (Khan B)  : PIN_51
  - SW[0]  (Ban dem) : PIN_52
  - SW[1]  (Pause)   : PIN_53

* BOTTOM HEADER (Cum LED 7 doan quet dong - PIN_110 den PIN_136):
  - Lan A Segments a..g : PIN_110, 111, 112, 113, 115, 119, 120
  - Lan A Digits 0, 1   : PIN_121 (Don vi), PIN_124 (Hang chuc)
  - Lan B Segments a..g : PIN_125, 126, 127, 128, 129, 132, 133
  - Lan B Digits 0, 1   : PIN_135 (Don vi), PIN_136 (Hang chuc)

* LEFT HEADER: De trong hoan toan 100% de thong thoang cho cong USB-C.
