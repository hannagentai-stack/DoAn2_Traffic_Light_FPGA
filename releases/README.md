ModelSim regression, file nạp và tài liệu. Gói được tạo lại ngày 17/11/2026 sau
cập nhật độ ổn định RTL abff943. Checksum nằm trong file .zip.sha256 bên cạnh.

Gói không bao gồm archive, build, database, work, .git hoặc ZIP lồng nhau.
Mở QPF tại thư mục gốc sau khi giải nén. SIMULATION=false khi tổng hợp/nạp thật.
